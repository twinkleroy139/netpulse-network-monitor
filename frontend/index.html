Network Status Thresholds

Online 2–45 ms latency, 0.5–4.5 ms jitter, and <0.5% packet loss represent a healthy local or wide area network.
Warning 50–150 ms latency, 5–15 ms jitter, and 1–5% packet loss accurately reflect network congestion or degrading hardware.
Offline 100% packet loss is the correct trigger for an unreachable node.
